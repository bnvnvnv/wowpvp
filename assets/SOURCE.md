## Local Blender assets (2026-09-06)

The following specific paths override the upstream directory mapping above:

- `art/models/weapons/custom/royal_sword_v1.glb`: original blue-steel sword, 1128 triangles, one vertex-color material.
- `art/models/weapons/custom/royal_shield_v1.glb`: original blue-and-gold crown shield, 1108 triangles, one vertex-color material.
- `source/royal-armory/royal-armory-v1.blend`: editable source and presentation scene, containing only this project's models and lighting.
- `art/ui/screens/royal-armory-v1.png`: Blender render of those two models.
- Author: this project; generated by `scripts/blender/build_royal_armory.py` through the local BlendMCP server using Blender 5.2. Project MIT license applies to these new models, source and render.
- `art/ui/screens/classes/warrior-royal-v1.png`: game capture combining the existing upstream warrior with these new weapons; the character retains the upstream provenance above.
- Existing weapon attachment bounds were inspected for compatibility. No reference mesh is included in the new weapon GLBs or their saved Blender scene. These are Blender assets and renders, not native AI image-generation output.
