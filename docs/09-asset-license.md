# 素材许可清单

> 规格书 18.2 与附录A#6：**素材必须先完成许可清单；未明确授权的图标、模型、音效和字体不得进入正式包。**
> 验收 #51：外部素材均有许可记录，不包含禁止再分发的项目专属资产。
>
> **顺序不能反：先登记，后使用。** 未登记的文件不允许出现在 `assets/` 里。

## 1. 核心原则

| 原则 | 说明 |
|---|---|
| **代码与素材许可分开管理** | 本仓库代码是 MIT，但**这不覆盖任何媒体资产**。参考项目是 MIT 不等于它引用的所有模型/图标都能自由使用（18.1） |
| **逐项登记** | 每个模型、动画、图标、音效、字体都要单独一行：名称、作者、来源、许可证、署名要求、商业使用、修改、再分发 |
| **授权不清晰 = 不能用** | 「看起来像免费的」「网上到处都有」不构成授权（18.2） |
| **不碰暴雪资产** | 不使用暴雪的角色模型、纹理、技能图标、地图文件、Logo、音频，不直接复刻场景布局（18.3） |

## 2. 明确可用与明确不可用

### ✅ 核对记录后可用

- **CC0 / 公有领域**素材：[Kenney](https://kenney.nl)、[Quaternius](https://quaternius.com)、
  KayKit 中**明确标记为 CC0** 的部分
- 自制原创素材
- 明确允许商业使用与再分发的 CC-BY（**必须按要求署名**，署名文本写进本文件和游戏内致谢页）

### ❌ 不得进入仓库

- 暴雪的一切资产：角色模型、纹理、技能图标、地图文件、Logo、音频、UI 素材（18.3）
- CraftPix 技能图标（18.2 明确点名）
- 参考项目 [world-of-claudecraft](https://github.com/levy-street/world-of-claudecraft) 的
  **定制武器、商店图、成就图标、品牌标识**，以及任何标记为「需要许可」的素材（18.2）
- 任何 NC（非商业）限定素材 —— 会限制项目未来的分发方式
- 任何**未登记或授权不清晰**的素材

### ⚠️ 关于参考项目

规格书 18.1 说得很清楚：

> 该仓库可以作为**人物、动作、移动手感、镜头碰撞和技能特效组织方式**的参考，
> 但**不能把所有媒体资源都视为 MIT 可自由使用**。

即：可以参考它**怎么做**，不能直接拿它的**素材文件**。
参考其骨骼命名约定、武器挂点结构、动画状态切换方式是允许的；
复制它的模型文件、贴图、图标不是。

## 3. 原创边界（18.3）

正式发布必须使用**原创**的：

- 游戏名称、阵营名称
- 职业包装（可以叫「战士」这类通用词，但职业标志、外观、口号必须原创）
- 技能名称（当前代码里用的是规格书给的中文名，**发布前需要一轮改名评估**）
- 地图、美术、音效、UI

可以参考的是：职业分工、目标制战斗、控制/打断/驱散博弈、自由镜头体验 —— 这些是**玩法机制**，不受版权保护。

> 📌 **待办**：当前代码中的技能名（冲锋、致死打击、圣光术…）直接来自规格书，
> 与《魔兽世界》技能名高度重合。发布前必须做一轮重命名。
> 由于技能名只在 `SkillDef.name` 一个字段里，改名成本很低 —— 但**不要拖到最后**。
> 已登记在 [10-acceptance-tracking.md](10-acceptance-tracking.md) 的待确认问题里。

## 5. 当前素材状态

**本仓库目前不包含任何外部媒体资产。**

M0–M3 的所有可视内容都用 three.js 的程序化几何体（盒子、胶囊、圆柱）与纯色材质构建，
不依赖任何外部文件。这是有意为之：

1. 在核心手感验证完成前引入美术资产是浪费
2. 程序化几何体让「统一战斗碰撞体」（13.2 / 验收 #10）天然成立 —— 没有模型胖瘦差异
3. 避免在早期就背上许可包袱

**引入外部素材的时机**：M8（表现层）。届时先填本文件的登记表，再下载文件。

## 6. 素材引入流程

```
1. 找到候选素材
2. 确认许可证 —— 找到明确的 LICENSE 文件或授权页面，截图/存档留证
3. 在本文件第 4 节登记表加一行
4. 若是 CC-BY 等需署名的许可证：
   同时把署名文本加入 assets/ATTRIBUTION.md 和游戏内致谢页
5. 才能把文件放进 assets/
6. 提交时在 commit message 里写明素材来源与许可证
```

**任何跳过第 2、3 步的提交都应当被拒绝。**

## 7. 发布前审计清单

- [ ] 所有需署名的素材已在 `assets/ATTRIBUTION.md` 和游戏内致谢页署名
- [ ] 没有任何 NC（非商业）限定素材
- [ ] 没有暴雪资产，没有参考项目的定制资产

- [ ] 字体许可证单独确认（字体常有独立于图像素材的分发限制）
