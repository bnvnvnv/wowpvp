## P2 真机压测：**怎么跑**（约 30 分钟，需要一台带独显的机器）

台子已就绪。以下是你要做的事 —— 结论会直接决定 P4（性能硬化）做不做、做哪些。

```bash
pnpm --filter @wowpvp/client dev      # 起客户端（默认 http://localhost:5173）
```

浏览器打开 **`http://localhost:5173/?stress`**（12v12 规模：24 个实体同屏开打）。

**要做的三件事**：

1. **拉远镜头**（滚轮拉到最远），让 24 个人全进画面 —— 最坏情况是「24 个人
   同时出现在屏幕上」，不是「场上有 24 个人」。等读数稳定 ~10 秒。
2. **记下四个数**：平均帧率、平均帧时间、**p95 帧时间**、绘制调用。
   ⚠️ 看 **p95** 不看瞬时 FPS：平均 60 帧但每秒卡一下 200ms 的体验是「卡」，
   瞬时读数看不出来。判读基线：p95 ≤ 20ms 舒服 · ≤ 40ms 可接受 · >40ms 明显卡。
3. **按 F2 逐档切画质**（高/中/低），各记一次 —— 低画质档掉不下来才说明
   自动降档（P9）真的有救。

**顺带回答「够不够炫」**（X10 的另一半，肉眼即可）：
- 陨星（大招）与霜矢（填充）的爆发**分量差别看得出来吗**（设计是 1.6 倍）
- 八属性的火/冰/奥术/暗影**一眼分得清吗**
- 哪几个技能看着"平"、该加料

**二分定位**（只在 `?stress` 掉帧时才需要）：`?stress=11` / `?stress=17`
往回试，找出「多少人开始掉帧」—— 那个数字直接指向瓶颈是每实体开销
（骨骼/材质，→ P8 instancing）还是特效池（→ 粒子预算）。

把这几个数发给我，我据此定 P4 到底做哪几项、要不要提前做。
